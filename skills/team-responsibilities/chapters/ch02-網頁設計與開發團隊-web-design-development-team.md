# Chapter 2: 網頁設計與開發團隊 (web-design-development-team)

## Core Idea
設計、開發及維護外匯報告的展示網站。需求分析：確定內容、樣式（專業、易讀、響應式）及功能（可透過 WSL IP 存取、Port 116688）。線框與視覺設計：製作低保真/高保真原型、選定配色、字母與佈局。前端實作：將每日外匯報告 Markdown 轉為 HTML，加入適當樣式（CSS/框架），確保響應式。測試與部署：使用本地 Python http.server（或其他伺服器）在指定 IP 與 Port 116688 提供服務，驗證可從 Windows 主機瀏覽器存取。維護：定期更新報告內容、修復樣式或功能問題。
