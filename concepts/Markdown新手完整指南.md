## 關鍵內容摘要
- Markdown 是純文字標記語言，由 John Gruber 和 Aaron Swartz 在 2004 年發明
- 核心優勢：向後相容性強（可追溯至 1963 年 ASCII）、與 Git 版本控制完美整合、內容與樣式分離
- 常見應用：README 檔案、技術文件、個人知識管理（如 Obsidian）、團隊協作（如 HackMD）、AI 輸出格式（ChatGPT、Claude 等預設使用 Markdown）
- AI 友好原因：Token 效率高（比 HTML 省 40-80%）、訓練資料豐富（GitHub 上幾乎每個專案有 README.md）
- 推薦工具：
  - 個人知識管理：Obsidian（免費、本機儲存、雙向連結）
  - 團隊協作：HackMD（雲端即時協作）
  - 程式開發：VSCode + Markdown 外掛
  - 寫作環境：Typora（所見即所得）
- 常見問題涵蓋：檔案開啟方式、數學公式（支援 LaTeX 語法）、轉換為 Word（使用 Pandoc）、與 Word 並用、複雜排版限制、手機支援、長期可用性
