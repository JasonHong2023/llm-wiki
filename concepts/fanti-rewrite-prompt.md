# 繁中潤稿（去簡體化）指令

來源：prompts.tw〈繁中潤稿〉（https://prompts.tw/p/fanti-rewrite），原文全文見 [[prompts-tw-fanti-rewrite-prompt]]。

## 用途

把簡體中文，或帶有大陸用語的繁體文字，改寫成台灣自然的繁體中文，同時輸出「原文詞 → 修改詞」對照清單。適合拿來潤飾翻譯稿、新聞稿、商品介紹和社群文案。

## 使用方式

指令有三個欄位要填：

- `{內容}`：要潤稿的文字。
- `{文體}`：文體類型，例如新聞稿、商品介紹、社群文案、學術文章。
- `{保留詞}`：品牌名、專有名詞、地名等不能改的詞；沒有就填「無」。

想額外替換特定的詞，可以在內容前面加一行，例如「額外替換：采购→採購、项目→專案」。

指令的規則分三部分：詞彙替換、語序調整（減少「的」字疊加、少用「被」字句、優先用主動語態）、台灣在地用詞。輸出包含潤稿後的全文和修改清單。

## 注意：對照表有幾組不能照套

| 對照 | 問題 | 建議 |
|---|---|---|
| 文件 → 檔案 | 台灣也說「文件」，指 document，例如官方文件、技術文件 | 只有指電腦檔案（file）時才換 |
| 關注 → 訂閱 | 意思不同；社群的「關注」在台灣多說「追蹤」 | 依情境換成「追蹤」或「留意」 |
| 非常 → 相當 | 「非常」是正常的台灣用語 | 不需要換 |
| 質量 → 品質 | 台灣的「質量」是物理學的 mass | 只有指 quality 時才換 |
| 實現、優化 | 指令本身也標了「視情境」 | 依文意判斷，不要一律替換 |

另外，網頁上的常見問答說指令包含「百餘組對照」，但實際指令裡只有大約 18 組。比較冷僻的大陸用語要自己補充。

## 與芥子的關係

芥子（jiezi_LLM）的 `src/jiezi/textconv.py` 本來就有簡轉繁和台灣用語轉換。2026-11-24 參考這份對照表後做了調整：

- 補上「聯系 → 聯繫」和「体 → 體」。
- 「文件」不再一律換成「檔案」。

其餘要看文意才能決定的詞組，沒有收進自動轉換，交給模型潤稿時判斷。相關的知識庫建構方法見 [[Andrej_Karpathy完整LLM_wiki_建構提示詞_基於ObsidianAI_Agent的個人知識庫完整建構]]。
