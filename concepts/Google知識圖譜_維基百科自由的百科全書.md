# Google知識圖譜

**Google知識圖譜**（英語：Google Knowledge Graph，也稱**Google知識圖**）是Google的一個知識庫，其使用語意檢索從多種來源收集資訊，以提高Google搜尋的品質。知識圖譜2012年加入Google搜尋，2012年5月16日正式發布[1]，首先可在美國使用。知識圖譜除了顯示其他網站的連結列表，還提供結構化及詳細的關於主題的資訊。其目標是，使用者將能夠使用此功能提供的資訊來解決他們查詢的問題，而不必導航到其他網站並自己匯總資訊。[2]

## 歷史

[編輯]據Google稱，知識圖譜的資訊來自許多來源，包括CIA的世界概況，Freebase和維基百科[1]。其功能與Ask.com和Wolfram Alpha等問題問答系統相似。

截至2012年[update]，其語意網絡包含超過570億個對象，超過18億個介紹，這些不同的對象之間有連結關係，用來理解搜尋關鍵詞的含義。[3][4]

2012年11月4日，知識圖譜新增了7種語言：西班牙語、法語、德語、葡萄牙語、日語、俄羅斯語及義大利語。[5][6]

在谷歌於2012年發布知識圖譜之前，Tim Berners-Lee於2006年就提出了Linked Data，是一種全球資訊網資料上建立語意關聯的方法。

更早之前，語意鏈網路（Semantic Link Network）已經開始了系統性的研究，目標是創立一個自組織的語意互聯方法來表達知識支援智慧型應用, 系統性的理論和方法作為專著發表於2004年。[7]之後,於2012年作了新的發展（詳細比較了與六十年代提出的語意網Semantic Net的區別）。[8]語意鏈網路研究可追溯到1998年繼承規則的定義[9]和2003年主動文件框架的研發ADF。[10]自2003年起它已經面向自組織的語意聯網方法發展。[11][12]推理和演化以及自動發現隱含規則在語意鏈網路中起重要作用。Tim Berners-Lee等專家於2006年出版的專著《A Framework for Web Science》就參照了早期關於語意鏈網路自動發現的工作。[13]近年來，語意鏈網路已經發展為支援資訊物理社會智慧型[14][15]，已經有了許多應用[16]。

## 對話搜尋

[編輯]在2013年5月的Google I/O大會上，Google的阿米特·辛格爾提出了未來搜尋引擎的設想：搜尋引擎的三個主要功能將需要改進，搜尋將需要：1.答案，2.對話，3.預測。作為他發表主題演講的一部分，阿密特說，「一台電腦，你可以與它交談嗎？它會回答你問的嗎？我成為我的為整個世界的夢想的負責人。」對話搜尋（英語：Conversational search）技術包含阿密特推出的一種「熱關鍵詞」的搜尋技術，不需要一個介面，即使用者只需將Google搜尋引擎說「OK Google」。[17]

在I/O大會上的觀眾演示，在其中一個使用者問了一個關於聖克魯斯地名的問題，搜尋引擎除了查詢結果的介紹，還以「談話」方式回答。Google的約翰娜·懷特解釋說，搜尋引擎使用知識圖譜的資料產生的結果：「知識圖譜知道，聖克魯斯是一個地方，且此列表與聖克魯斯有關。」[17][18]
