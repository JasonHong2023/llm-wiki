## 一、K線戰法：追價力與轉折確認（第一章）

### 核心價值觀：做多的基礎在「追價力」
**追價力**＝買盤積極到不計價搶進、願意排隊買也買不到的力道，反映在分時走勢上是股價快速噴出並維持高檔，而非緩慢震盪堆疊上去的「拉抬力」（拉抬力=低成交量硬拉，缺乏追價力，即使當天也是漲停，仍不是理想標的，且要留意流通性風險）。

### 四手紅盤：主力進場的具體判讀門檻
- **定義**：連續4根長紅K（大型權值股3根長紅即可）稱「四手紅盤」，代表主力連續買進，讓套牢者解套，行情才剛開始。
- **成立門檻（避免濫用）**：至少要有3根漲停或4根長紅，且4天內漲幅要達**30%以上**才算數，不是隨便4根紅K就叫四手紅盤。
- **量能**：四手紅盤成交量放大是常態；無量鎖死漲停（賣方惜售）更強勢，但要避開僅幾百張成交量、有流通性風險的個股。
- **回檔型態（多空比較）**：四手紅盤飆漲後會拉回整理3-5天、幅度10-15%，回測MA10（極強勢股僅拉回MA5），只要沒跌破上漲段最後2根紅K的低點就是安全的買點；若跌破最後第2根紅K低點，視為空方勝、應短線出場。
- **反向訊號（四手黑盤）**：連續4根長黑（大型股3根）代表主力偷溜，必須立即出場，不能心存僥倖凹單；大盤出現2根長黑或摜破月線，須減碼避險。

### 3K買賣法（短線轉折訊號）
- **買點**：當根K線最高點突破前2根K線的最高點。
- **賣點**：當根K線最低點跌破前2根K線的最低點。
- **適用週期**：日線、週線適用；**月線不適用**（月線3K法用來判斷長期趨勢，不是拿來買賣的訊號）。
- **加強濾網**：3K法突破同時搭配當日漲幅**5%以上**，勝率達70%——這是全書反覆引用的核心公式，適用當沖、隔日沖、波段操作。
- **出場邏輯（日線3K法作為短線調節工具）**：3K法日線跌破時賣出、股價拉回MA10或MA20（月線）再買回，屬於「降低持股成本」的短線調節做法；若是週線3K法尚未跌破，屬於長線抱牢的單股操作邏輯，不受日線波動影響。

## 二、移動平均線操作規則（第二章）

### 均線分類與角色
- **MA5**（週線）／**MA10**（波段線）：短期均線，飆股沿MA5、MA10上漲，拉回至此具強勁支撐，是波段操作的停利參考位置。
- **MA20**（月線）：中期均線，代表一個月的平均成本。中長線投資人可用MA20作停利參考——跌破MA20先出場避開修正風險（修正幅度可達2-3成），重新站上MA20再買回。
- **MA60**（季線，又稱**生命線**）：季線不守，絕對、絕對不能攤平（原書用詞強調兩次「絕對」）。
- **MA240**（年線）：多空市場的分野。股價從高檔跌到年線通常有強勁支撐、不會一次跌破，年線是搶反彈點；但若確立空頭，年線會反覆測試直到真正跌破，一旦跌破就確定進入空頭市場。

### 助漲力／助跌力（扣抵位置的意義）
股價從均線下方突破向上、均線也開始上彎時，均線提供支撐（助漲）；當均線減速、股價再次靠近均線時，代表均線正在失去助漲動能，此時應避開拉回風險（不是均線本身失效，是均線的「加速度」在變化，這是原書判讀均線強弱的關鍵，不是單純看價格在均線上方或下方）。

### 多空翻轉的均線攻防順序
- **空翻多**：先突破MA10 → 再攻MA20（月線）→ 挑戰MA60（季線）→ 直到收復MA240（年線），才能確立由空翻多。
- **多翻空**：跌破MA10 → 向下測試MA20 → 跌破MA60 → 測試MA240，順序相反。

## 三、123波浪法則（第三章，Elliott波浪理論的天機圖版本）

### 多頭市場：五波上升結構
1. 漲升結構必由五波組成。
2. 除非一、三波延伸，否則第三波漲勢最強、幅度最大、時間最長。
3. 除非一、三波延伸，否則第四波低點應高於第一波高點。
4. 一、三、五波中有一波可能延伸，第三波機率最大。
5. 跌破二、四波的上升支撐線，代表五波結束。

### 空頭市場：三波下跌結構（ABC，各波可再細分五波）
1. 下跌結構必由三波（A、B、C）組成，A、C波又可各自細分為五波下跌。
2. 反彈B波量能小於A波，容易價量背離。
3. A、C波的第一、五波若無延伸，則第三波跌勢應最強、幅度最大、時間最長。
4. 同上前提下，第一波低點應高於第四波高點。
5. A、C波的第一、三、五波中有一波可能延伸。
6. 突破之前五波高點與B波下降壓力線，代表三波下跌結束。

### 空頭五波各段落的心理描述
第一波（初跌段，跌幅不大，本益比偏高股修正為主）→ 第二波（多方搶短或加碼，價漲量縮的空頭跡象已現）→ 第三波（主跌段，空頭確立，多殺多）→ 第四波（超跌反彈，套牢者惜售，但賣壓仍重不宜追價）→ 第五波（末跌段，量能漸縮，抗跌股補跌）→ A波（反彈但量不足，追價意願薄弱）→ B波（解套賣壓出籠、股價壓回）→ C波（若無量以停損為主，可能進入下一段跌勢）。

### 波浪的時間尺度分級（大到小）
天機圖的波浪理論分**巨浪（月線）**、**大浪（週線）**、**小浪（日線）**——這是天機圖自己的簡化三層分類。原書同時列出正式Elliott波浪的完整級別命名（大到小）：Grand Supercycle → Supercycle → Cycle → Primary（基本浪）→ Intermediate（中型浪）→ Minor → Minute → Minuette → Subminuette（次微浪），可對照使用，但天機圖實際操作只用「巨浪/大浪/小浪」三層簡化版。

**波段操作經驗法則**：大盤平均每年有兩次以上的「週線大買點」（大浪級別的低點），要好好把握、逢低提高持股比重。

## 四、型態學與時間循環（第四、五章——第四章OCR大量缺失，僅存框架）

### 型態學（第四章，內容嚴重缺失，僅存以下可確認片段）
原書確實教過至少以下型態名稱：**上升旗型**（多頭整理型態，高點越來越高、低點也墊高）、**雙重底**、**圓形底**（底部反轉型態），以及**費波南茲數列**（Fibonacci sequence）在型態學裡的應用，明確提到比率**0.382**、**0.5**、**0.618**（黃金分割常用回撤/支撐壓力比率），數列本身如34、55、89、144……。**這幾個型態的具體進出場規則、頸線突破確認條件等，因原書該部分頁面OCR大範圍失敗，無法從現有擷取資料還原，需要之後重新查證原書對應頁碼（第34-45頁附近）才能補齊。**

### 時間循環：13天費氏時間轉折法則（第五章，完整可用）
- **核心觀察**：日線波段中，KD值從空方區(20)漲到多方區(80)，平均約需**13天**——天機圖以此把「13」定為標準時間轉折基準。
- **時間延伸規律（跟隨費波南茲數列）**：若股價上漲超過13天循環、KD呈多頭鈍化（80以上），代表不只漲空間也漲時間，接下來的時間節點依序看**21、34、55、89**天——多頭鈍化的股票不預設價格高點，要用時間循環而非價格目標去判斷還能不能抱。空頭方向對稱：跌破13天循環、KD空頭鈍化，續跌時間節點看21、34、55天。
- **回檔時間分類**：
  - 拉回3-5天：正常的短暫拉回（尤其KD多頭鈍化後的健康整理）。
  - 拉回5-8天：**KD多頭循環**的典型修正時間，長期多頭趨勢不變，整理完可再創新高。
  - 拉回8-13天：**KD多空循環**，長多趨勢雖沒變，但短期方向不明，短線應避開。
  - 拉回超過13天：在高檔盤整時若拉回時間超過13天，就會反轉向下，須小心多頭市場轉向。
- **操作紀律**：多頭市場上升趨勢中，每一次多方攻擊必須在13天內過新高，一旦超過就要提高警覺。

## 五、KD戰法（第六章——本書最具特色、跟既有蒸餾文件差異最大的部分）

### 天機圖專用KD參數：9,2（不是坊間慣用的9,3,3）
既有《[技術分析參考：技術指標與K線型態](./技術分析參考_技術指標與K線型態.md)》記載的KD標準參數是9,3,3。本書**明確採用不同參數9,2**，理由是原書認為市面上震盪指標多達30幾種、互相矛盾，天機圖操盤法選擇只專精KD一種指標、把其他價格類指標的功能都吸收進來，避免多指標互相打架。

### 2種鈍化、3種循環、4個區域（天機圖自訂的KD分區框架，跟標準9,3,3的超買超賣定義不同）
- **2種鈍化**：多頭鈍化（KD80以上）、空頭鈍化（KD20以下）。
- **3種循環**：多頭循環（KD 50→80）、多空循環（KD 20↔80雙向）、空頭循環（KD 50→20）。
- **4個區域**：大漲區（80以上）、多方區（50以上）、空方區（50以下）、大跌區（20以下）。

### 明確反駁坊間「KD20以下超賣應買進」的說法
原書用真實案例反駁：易華電(6552)在KD20以下空頭鈍化時進場做多，收盤價62.5元，13天後續跌到42.8元，修正超過3成——**KD值20以下不代表就是買點，若同時處於空頭鈍化（跌時間也跌空間），反而應該避開，不是逢低承接**。同樣地，多頭鈍化（KD80以上）也不代表要賣出——長榮(2603)案例：若在KD80以上就賣出，會錯過後續長達11個月的漲勢。**這是本書最核心的風控提醒：KD的鈍化/循環狀態要合併判讀，不能只看數字落在哪個區間就套公式。**

### KD多頭循環的操作意涵
當KD從50向上再度交叉往上形成多頭循環時（約需5-8天形成），代表股價會過前高，是買進訊號；做多應優先選擇「多頭鈍化」或「多頭循環」的股票。

### KD背離
- **正背離（牛市背離）**：股價創新高，KD值不創新高——短線可能拉回，但股價趨勢仍向上，應在拉回找買點，不要逆勢放空。
- **負背離（熊市背離）**：股價破新低，KD值不破新低——短線可能反彈，但股價趨勢仍向下，應在反彈找賣點，不要逆勢做多。

### 跨週期KD交叉規則
1. 月KD交叉向上、週KD交叉向下拉回 → 伺機買進。
2. 週KD交叉向上、日KD交叉向下拉回 → 伺機買進。
3. 週KD交叉向下拉回、日KD交叉向上反彈 → 伺機賣出或放空。

### 月KD極端值的長線定位訊號（附大盤歷史回測經驗）
- **月KD來到高檔80**：除2017、2021年曾延續5-8個月才拉回外，歷史經驗顯示大盤月KD一旦到80，多半有拉回風險，應提高風險意識、調整資金配置。
- **月KD來到低檔20**：歷史上發生機會非常少，一旦出現代表再下跌空間有限，可分批逢低布局，屬於長期難得的財富重分配機會。

## 六、天機圖的飆股模式（第八章）

### 甘氏角度線（Gann Angle）
縱座標為價格、橫座標為時間，角度換算表：

| 比例 | 角度 |
|---|---|
| 1×1 | 45° |
| 1×2 | 63¾° |
| 1×3 | 71¼° |
| 1×4 | 75° |
| 3×1 | 18¾° |
| 4×1 | 15° |
| 8×1 | 7½° |

**判讀規則**：45°是多空分界角度，45°以下不做多；應尋找**60°以上**的股票做多，坡度越陡越好。

### 主力股（強勢股）的技術面辨識三條件
1. 股價大漲小回，站穩MA5、MA10之上，時間週期符合費波南茲天數（55、89、144天）。
2. KD在80以上（多頭鈍化）。
3. 甘氏角度線在60°以上。

### 投信認養訊號
投信偏好認養有前景、有業績的成長股，操作週期較長，搭配題材容易成為市場熱門股。**要特別留意投信作帳行情的時間窗口：3、6、9、12月，尤其是6月與12月（年報前後）**；大盤表現不好時，若有個股逆勢上漲、盤後發現投信剛建倉，可積極跟單。

### 「漲一倍模式」六點確認清單
1. 突破下降趨勢線、站上季線。
2. 四手紅盤、跳空上攻（K線戰法多方確認）。
3. 符合123法則、前波段有過大漲紀錄。
4. 日週KD值80以上、多頭鈍化。
5. 股價拉回MA5、MA10可買進（非頭部，是上漲一波整理完再上漲）。
6. 當天股價從漲停殺到跌停視為出貨訊號（等同2根倒T字線跌破），要在當天賣出。

## 七、六種股票操作模式（第九章，天機圖操盤法的核心分流架構）

原書標題自陳「六大操盤法」，實際整理出的六種模式與各自的持有週期、適用對象：

| 模式 | 適用市況／對象 | 操作週期 |
|---|---|---|
| **3K法**、**熱門股當沖法** | 短線交易 | 極短線（當沖/隔日沖） |
| **投信買超法**、**天機圖操盤法** | 大盤走多頭2法則時，波段主流股；大波段持有投資人 | 13-55天 |
| **123格局操盤法**、**單股操作法** | 多頭市場長線持有；基本面大成長、熱門產業繁榮期個股；長期投資人 | 89天以上 |

### 單股操作法／123格局操盤法要點
- 進場前提：確認明年業績成長預估**年增30%以上**，搭配四手紅盤確認。
- 操作規則：跌破MA10賣出，站上MA20再買回，直到產業前景出現疑慮才真正結束操作——技術性紀律操作，不預設任何立場，持有時間可長達2-3年。
- 也可搭配格局操盤簡化交易次數：格局1買回、格局A賣出，避開ABC修正波，減少進出次數、節省交易成本（格局法則定義見下）。

### 格局法則（123/ABC，判斷股票所處的大格局階段）
- **格局1**：突破下降趨勢線、站上季線、反彈過前波高乘以1.3。
- **格局2**：跌破月線。
- **格局3**：過前波高。
- **格局A**：跌破上升趨勢線、跌破季線、跌破前波高乘以0.7。
- **格局B**：反彈站上10日線。
- **格局C**：破前低（多頭市場的C波不一定會破前低）。

大盤格局會呈現「2→3→2→3」這種格局間的循環往復。

### 投信買超法／天機圖操盤法要點
即使投信買超的股票基本面良好，大盤走入空頭市場時同樣會被拖累下跌——投信認養不是免疫於系統性風險的保證，仍需搭配大盤格局位置判斷。

## 八、天機圖組合拳：完整SOP（第十章）

### 四大工具的分工
- **K線** → 找轉折點。
- **移動平均線** → 判斷移動方向與成本。
- **時間轉折**（費氏13天法則）→ 判斷股價運動所需時間。
- **123法則** → 判斷目標位置（波浪級別的價格目標）。

### 操作SOP順序
1. 判斷轉折點：長紅(黑)K線、3K法突破(跌破)，任一出現即視為轉折確認。
2. 先判斷大盤格局、再判斷個股格局——大盤格局決定多空方向與資金投入比例，個股格局影響進場時機與部位大小。
3. 規劃大盤日線每一波的時間轉折（8天與13天為基準），標出波段高低點。
4. 用KD作為確認指標，判斷格局走勢是否符合預期，避免只看K線陷入「見樹不見林」的技術面盲點。

### 補充確認訊號（組合拳操作細節）
- 3K法突破越強（漲停力道越大），MA5助漲力越大；反之3K法跌破會回測MA10、MA20。
- KD鈍化即代表主升段確立，應抱緊持股度過MA5/MA10的洗盤震盪，只要漲勢超過13天都算主升段延續。
- 永遠優先買進「KD多頭循環」與「KD多頭鈍化」的股票——避開KD多空循環（方向不明）的個股。
- 避開K線小漲小跌的冷門股，操作效率低。

## 九、內功心法：交易紀律格言選錄（第十二章，原書列出32條，本書大量頁面OCR缺失，以下是能完整還原、確定原意的條目）

1. **股市兩國論**：台股實際上是兩個市場——上市（台北股市）與OTC（櫃買）並存，資金會在兩者間流動；大盤歷史高點18619點是外資買出來的，低點16764也是外資砍出來的，外資大買大賣常跟期指結算連動；盤整期時中小型股表現通常優於大盤。
2. **停損執行力**：紀律的核心不在於知道要停損，而在於真的能執行。
3. **跟著指數走**：個股表現終究受大盤格局牽動，不能脫離大盤格局單獨判斷個股。
4. **作多賺得多，作空賺得快**：多空操作的獲利節奏本質不同，作多是累積型獲利、作空是速度型獲利。
5. **拒絕未符合條件的訊號**：技術面條件不到位（例如未過前高、KD未過某門檻），不要因為想交易而硬找理由進場。
6. **技術面領先基本面3-6個月**：市場上永遠有資訊優勢者提前佈局，技術面（量價）的反應通常比基本面消息公布早3-6個月——原書舉天鈺(4961) 2020年11月的案例，技術面訊號出現在後續營收/驅動IC題材公開發酵之前。
7. **當沖的目的在避險，短線交易的目的在cost down降低成本**：兩者目的不同，不要混為一談去操作。
8. **估不準沒關係，但要常常打勝仗**：交易紀律的重點是長期勝率跟執行的一致性，不是單次判斷的精準度。
9. **四隻動物人格特質**：用來自我評估交易個性——**鷹**（銳利眼光，擅長基本面/產業面分析，懂得找主流股）、**駱駝**（耐心、恆心、毅力，適合長抱）、**小孩**（最不穩定的操作人生，得失總在三分鐘之間，衝動型交易者）。原書要求讀者先認清自己屬於哪一種動物特質，再選擇適合自己的操作模式（呼應第九章六種模式各自適合不同持股週期與個性的設計邏輯）。
10. **不要當散戶**：即使資金規模是散戶等級，操作紀律與判斷邏輯不應該用散戶的方式思考。
11. **股票不分好壞，只分前後**：不要用主觀「好公司/壞公司」的價值判斷去篩選標的，重點是動能出現的時間點——早期介入還是後知後覺介入。
12. **買的是慣性，不是股名**：交易的是股價上漲的慣性與推升動能，不是公司知名度——冷門、陌生的股票反而因為籌碼乾淨，一旦啟動漲勢更純粹。
13. **要在熱，不要在冷**：偏好資金與人氣聚集的熱門股，不是價值面的「便宜貨」，這是明確的動能交易哲學，跟價值投資邏輯是對立的立場（可對照既有蒸餾文件《[技術分析參考：價值投資通用原則](./技術分析參考_價值投資通用原則.md)》，兩者代表的是同一個市場裡兩種對立的操作哲學，本書明確站在動能交易這一邊）。
14. **持股太雜，必輸無疑**：分散持股到10-20檔以上會稀釋績效、難以管理，原書統計發現過度分散的投資人反而「越攤越貧」。
15. **長短不分，白忙一場**：不要把短線交易的心態套用在長線持股上（或反之），會導致操作邏輯自相矛盾、白忙一場。
16. **賺錢才加碼，賠錢不攤平**：只在方向判斷正確、部位獲利時才加碼放大部位；虧損部位絕對不攤平——這是全書唯一一條跟FX_Trading系統既有規則（「賺錢就加碼、賠錢不攤平/不逆勢攤平」的既定風控原則）完全一致的具體條文，可視為交叉驗證。
