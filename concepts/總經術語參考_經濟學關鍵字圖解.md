## 一、國際經濟與外匯機制（Chapter 2 完整深度）

### 貿易與國際收支的層層疊加關係
- **貿易收支** = 出口額 − 進口額（負數＝貿易逆差，正數＝貿易順差）
- **經常收支** = 貿易收支 + 勞務交易等收支
- **國際收支** = 經常收支 + 資本收支
- **比較優勢原理**：國與國之間互相出口各自具有比較優勢的商品，能創造出比自給自足更大的整體利益，是自由貿易的理論基礎。

### 關鍵貨幣與外匯市場
**關鍵貨幣**（硬通貨幣）：各國選擇用來當作外匯存底、占有主流地位的貨幣。**外匯市場**是進行貨幣交易的市場，外匯匯率隨時都在變動。

### 經濟整合的層級（FTA只是起點）
由淺入深：**FTA**（自由貿易協定，關稅減免）→ **EPA**（經濟夥伴協定，範圍更廣，含投資/人員往來）→ 區域性協定如**NAFTA**（加拿大、美國、墨西哥）、**AFTA**（ASEAN十國）→ **TPP**（跨太平洋夥伴協定）、**RCEP**（東亞區域全面經濟夥伴協定）→ 終極形態是**歐元區**這種貨幣同盟。

### 歷次金融危機的時間軸
1997年亞洲金融風暴 → 2007年次貸危機 → 2008年雷曼事件 → 2010年歐債危機。**雷曼事件爆發後，資訊科技業界陸續建立起新的金融服務，也就是金融科技的興起**——原書明確把金融科技的誕生歸因於雷曼事件後傳統金融體系信任受創、市場轉向科技解方的結果。

## 二、GDP測算與景氣循環理論（Chapter 6 完整深度）

### GDP的三面等價原則
SNA（國民經濟會計）衡量總體經濟活動，**GDP（國內生產毛額）＝GDI（國內所得毛額）＝GDE（國內支出毛額）**，三個金額理論上完全相等，這就是「三面等價原則」——生產出來的東西必然等於分配出去的所得，也必然等於花掉的支出，這是總體經濟會計恆等式，不是巧合。

### 名目GDP vs 實質GDP
未排除物價變動影響的是名目GDP；排除物價變動影響的是實質GDP。兩者的差距即反映當期通膨/通縮的幅度。

### 景氣循環四大理論（依週期長短排列，這是本書最有價值、且既有蒸餾文件完全沒有的內容）

| 週期名稱 | 發現者 | 週期長度 | 成因 |
|---|---|---|---|
| **基欽週期** | 約瑟夫・基欽（美） | 約40個月（短期） | 企業存貨變動所形成的波動 |
| **朱格拉週期** | 克萊門特・朱格拉（法） | 約10年（中期） | 企業設備投資變動（與設備耐用年數相近） |
| **庫茲涅茨週期** | 賽門・庫茲涅茨（美） | 約20年 | 住宅、商業大樓等建築物的重建或整修 |
| **康德拉季耶夫週期** | 尼古拉・康德拉季耶夫（蘇） | 約50年（長期） | 技術革新（熊彼得提出解釋）——原書具體舉例：1780年代蒸汽機/紡織機/工業革命 → 約60年後1840年代鋼鐵/鐵路 → 約50年後1890年代電力/電信 → 約40年後1930年代化學/汽車，每一波週期都對應一次重大技術革命 |

**操作意涵**：這四個週期並存、疊加運作，短週期（基欽）波動最頻繁、長週期（康德拉季耶夫）決定大方向；判讀當下總經數據時，應該分辨眼前的變化是短週期的存貨調整雜訊，還是長週期技術革新驅動的結構性轉折。

### 景氣動向指數的三分類
**領先指數**（預測未來）、**同時指數**（反映當下）、**落後指數**（確認已發生），對應**CI（綜合指數）**跟**DI（擴散指數）**兩種量化呈現方式。

### IS-LM模型（凱因斯經濟學分析利率與所得的核心工具，既有文件未收錄）
凱因斯經濟學認為決定GDP等國民經濟水準的是**有效需求**，探討的市場有三種：產品市場、貨幣市場、勞動市場。**IS曲線**反映產品市場供需均衡下的利率與國民所得關係；**LM曲線**反映貨幣市場供需均衡下的利率與國民所得關係；兩條線的交點求出均衡利率與均衡國民所得，這就是IS-LM模型。當中央銀行增加貨幣供給時，LM曲線會下降，結果是**利率下降、國民所得增加**——這是理解「央行放水為什麼會壓低利率」的正式數學工具，不只是直覺描述。

## 三、央行貨幣政策的具體機制（Chapter 7 完整深度，本書最有價值的部分）

### 乘數效應與乘數公式（既有文件只提概念，這裡有完整公式跟worked example）
政府公共投資或減稅的效果不只限於支出金額本身，會透過「有人的支出變成別人的收入、別人的收入又拿去部分消費」的連鎖反應放大數倍：

$$\text{乘數} = \frac{1}{1-c}$$

其中 c 是**邊際消費傾向**。書中例子：邊際消費傾向0.8時，乘數 = 1/(1-0.8) = **5倍**——政府投入5億圓公共投資，最終能創造出25億圓的國民所得增幅。

### 排擠效果（Crowding Out）的具體傳導路徑
政府發行國債籌措公共投資財源 → 市場利率上升 → 民間投資/消費因為利率變貴而減少 → 部分抵銷原本預期的乘數效應。**流動性陷阱**是排擠效果不會發生的特殊情況：當利率已經低到停滯不動，即使政府發行國債，利率也不會再進一步上升，乘數效應因此能完整發揮——但代價是這種情況下，中央銀行想再靠降息刺激經濟也沒有空間了（貨幣政策失靈），人們此時偏好持有貨幣勝過持有幾乎沒有利息的債券。

### 財政赤字的可持續性：兩套判斷條件
- **多馬的條件**：只要**名目GDP成長率**維持在公債名目利率之上，即使長期財政赤字也不會面臨財政破產（債務餘額占GDP比重不會持續增加）。
- **鮑恩的條件**：當前期債務餘額占GDP比重惡化時，只要讓今後基本財政收支的GDP比重持續改善即可避免破產。

### 李嘉圖-巴羅等價命題：發公債跟增稅有沒有差別？
- **李嘉圖等價命題**：公債的發行等於增稅，因為理性民眾會預期未來政府必須增稅還債，因此提前減少消費、增加儲蓄——所以發債跟增稅在經濟上是中立的，差別只在「先增稅還是後增稅」。
- **巴羅的等價命題**：延伸到跨世代情況——即使這一代不用還債，因為有「遺產」的存在，這一代仍會為了讓子孫償債而提前減少消費、留下遺產，所以即使橫跨世代，等價命題依然成立。

### 貨幣供給層級（M1/M2/M3/廣義流動性，日本央行的官方分類，比既有文件更細）
- **M1** = 現金貨幣 + 存款貨幣
- **M2** = M1 + 準貨幣 + CD（發行者限定國內銀行）
- **M3** = M1 + 準貨幣 + CD（發行者涵蓋所有存款貨幣機構，範圍比M2廣）
- **廣義流動性** = M3 + 金錢信託 + 投資信託 + 金融債券 + 公司債 + CP + 國債 + 外債

### 馬歇爾K值：判斷貨幣供給是否過量的指標（既有文件未收錄）
$$\text{馬歇爾K值} = \frac{\text{貨幣供給}}{\text{GDP}}$$
數值越大代表市場上流通的錢相對GDP越多。判讀方式：拿當下的K值跟長期趨勢線比較，或跟他國數值比較，偏離趨勢過多即代表貨幣供給可能過量或不足。

### 信用創造機制：央行的「強力貨幣」如何被銀行體系放大數倍
**強力貨幣**（貨幣基數）＝央行發行的現金貨幣 + 商業銀行存在央行的存款準備金——這是央行唯一能直接控制的貨幣數量。透過**信用創造**，這筆錢會在銀行體系裡被放大數倍：銀行收到100億圓存款、扣除10%存款準備金後，把90億圓貸出去，這90億圓花掉後又會有一部分回流存進另一家銀行，然後這家銀行又能貸出其中90%……如此循環，最終貨幣供給會被放大成強力貨幣的數倍。這個放大倍率就是**信用乘數**：

$$\text{信用乘數} = \frac{1}{\text{存款準備率}} = \frac{\text{貨幣供給}}{\text{強力貨幣}}$$

存款準備率10%時，信用乘數理論上是10倍；準備率5%時是20倍。**現金存款比率提高（大家把錢存在家裡不存銀行）或銀行信貸緊縮，都會讓實際信用乘數低於理論值**。

### 日銀政策利率工具的演進史（既有文件沒有這個時間軸）
公定步合操作（到1994年，商業銀行利率完全自由化前的傳統工具）→ 無擔保隔夜拆款利率（到2013年，透過公開市場操作誘導）→ 基本貼現及放款利率（2006年更名）→ 2013年量化與質化貨幣寬鬆政策上路後，操作目標從利率轉為**貨幣基數本身**，利率目標朝負利率發展。

### 公開市場操作的具體工具清單（日銀2017年官方資料）
- **賣出操作**（資金回收）：日銀票據、國債附買回、國庫短期證券
- **買進操作**（資金供給）：國債、共通擔保資金供給操作（債券擔保貸款）、CP公司債、ETF/J-REIT

### 最終貸款人的兩個真實案例
2008年紐約聯邦準備銀行融資給因次貸危機重傷的貝爾斯登；1997年泡沫崩壞後，日銀根據日本銀行法提供「日銀特殊融資」給破產的北海道拓殖銀行和山一證券——中央銀行扮演「最終貸款人」是穩定金融體系的關鍵功能，不是紙上條文。

### 貨幣中立性：凱因斯學派 vs 貨幣主義的分歧
**貨幣中立性假說**主張貨幣量的增減在經濟上是中立的，不影響消費/投資/GDP成長，只影響物價。**凱因斯經濟學（短期視角）**：貨幣供給增減會影響消費/投資/GDP，因此可以用貨幣政策管理總合需求。**貨幣主義（長期視角）**：貨幣供給增減只會反映在物價上，不會影響實質經濟，裁量式的貨幣政策是不好的。**目前普遍接受的折衷立場：長期來看貨幣中立性成立，但短期而言貨幣政策對實質經濟仍然有效**——這正是各國央行短期積極干預、但長期目標仍鎖定物價穩定的理論依據。

### AD-AS模型：物價與GDP如何同時被決定
總合需求 Yd = C + I + G（消費+投資+政府支出）；總合供給 Ys = C + S + T（消費+儲蓄+租稅）。AD曲線（向右下傾斜）與AS曲線（向右上傾斜）的交點決定均衡價格與均衡GDP。財政/金融政策擴張時，AD曲線右移，GDP與物價同時上升——但即使達到這個均衡，勞動市場未必達到充分就業，可能仍有非自願性失業存在（**工資向下僵固性**：勞動者不接受低於某個水準的工資，導致低工資水準下勞動供給過剩、非自願性失業產生）。

## 四、經濟學派的立場光譜（Chapter 8，中等深度——理解各派立場有助於判讀央行官員談話背後的理論傾向）

| 學派 | 核心主張 | 對政府角色的立場 |
|---|---|---|
| **重商主義**（16-18世紀） | 財富＝金銀，靠出口累積 | 保護貿易、對進口課關稅 |
| **重農主義**（18世紀法國） | 財富源自農業 | 批判保護貿易、主張自由放任 |
| **古典經濟學**（史密斯/馬爾薩斯/李嘉圖/穆勒） | 勞動價值論；供給會自行創造需求（**賽伊法則**） | 自由放任、小政府 |
| **馬克思經濟學** | 剩餘價值理論——資本家剝削勞動者創造的超額價值 | 主張推翻資本主義 |
| **新古典經濟學**（1870年代邊際革命：傑文斯/門格爾/瓦爾拉斯） | 價值取決於邊際效用（非勞動量），邊際效用遞減 | 延續自由市場立場，加入數學化分析（一般均衡理論） |
| **凱因斯經濟學**（1930年代經濟大恐慌後） | 有效需求原理、工資向下僵固性、流動性偏好 | **大政府**——政府應主動管理總合需求（凱因斯政策） |
| **芝加哥學派／貨幣主義**（傅利曼，1970年代停滯性通膨後興起） | 貨幣中立性、反對裁量式財政干預 | **小政府**——新自由主義，只用固定規則管理貨幣供給 |
| **供給面經濟學** | 透過減稅/鬆綁刺激生產面，而非管理需求面 | 影響雷根經濟學、柴契爾主義 |
| **行為經濟學**（近代，多位諾貝爾獎得主） | 將心理學觀察納入模型——例如展望理論的**參考點依存性**（人們評估效用時依賴一個參考基準點，不是絕對值）與**損失趨避性**（承受損失的痛苦感受強過獲得等量收益的快樂感受） | 解釋人類「不合理」的實際投資/消費行為，跟古典理性人假設互補 |

**歷史模式**：1930年代經濟大恐慌讓古典學派讓位給凱因斯學派（大政府）；1970年代停滯性通膨讓凱因斯學派讓位給貨幣主義（小政府）；1990年代起全球經濟動盪時貨幣主義也顯露侷限，人們又重新檢視凱因斯政策——**經濟政策主流思潮本身會隨危機型態鐘擺式轉換，沒有哪一派永遠正確，判讀當下央行政策傾向時，要留意它是在哪個鐘擺位置上做決定**。
