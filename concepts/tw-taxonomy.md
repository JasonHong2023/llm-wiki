# tw-taxonomy：以 108 課綱為本的台灣國小學習知識圖譜

tw-taxonomy 是 GitHub 上的開源專案（seyen37/tw-taxonomy），把 108 課綱各領域的「學習重點」拆成細粒度的「微主題」，再用先修關係串成有向無環圖（DAG），用途是讓開發者做個人化的 AI 教育工具與兒童學習應用。

## 規模與資料

- 版本 v1.0.0，涵蓋 15 個領域（九大領域＋生活課程＋六個選修語文）。
- 569 個微主題、717 條先修關係。每個微主題有穩定識別碼、類型、領域、學習階段、精熟證據判準、家長檢核提示與差異化教學任務。
- 微主題對應 108 課綱的學習內容代碼（例如 math:N-1-1）與學習表現代碼（例如 math:n-Ⅰ-1）。
- 資料放在 `data/` 目錄，JSON 格式：微主題、先修關係、課綱條文、家長摘要與校驗和。

## 工具與用法

- `gen_lesson_plan.py` 依領域與年級產生逐課設計表，包含先備概念、教學法與評量。
- 三種個人化流程：預習型（沿先修鏈複習）、複習型（用檢核提示找弱點）、補救型（鞏固中心性高的基礎概念）。
