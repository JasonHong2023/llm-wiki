## 一、K線基礎與單根K線判讀

### K線組成
- 由「開盤價」「收盤價」「最高價」「最低價」四個價位組成，實體代表開收盤價之間的區間，實體以上細線是「上影線」（代表當日最高價），實體以下是「下影線」（代表當日最低價）。
- 收盤價高於開盤價 → 紅K（陽線）；收盤價低於開盤價 → 黑K（陰線）；收盤價等於開盤價 → 十字線。
- **重要提醒**：紅K/黑K只反映「當日開盤價 vs 收盤價」的相對關係，跟「今天比昨天漲or跌」是兩回事——開低走高可能收紅K但仍較昨日收盤價低；開高走低可能收黑K但仍較昨日收盤價高。判讀時不要把「收紅/收黑」直接等同於「上漲/下跌」。

### 上下影線的意義
- 上影線代表「現買現虧」的區域：影線越長，代表該價位曾經有較多買盤進場卻遭套牢，是短線上檔壓力的來源，上影線長 → 賣壓重、後市看淡。
- 下影線代表「現買現賺」的區域：影線越長，代表逢低承接力道越強，是短線下檔支撐的來源，下影線長 → 支撐強、後市看好。

### 六種紅K基本型態
| 型態 | 判讀 |
|---|---|
| 長紅K（開=低、收=高） | 最強勢上漲格局；出現在下跌末端可能是反轉訊號，出現在上漲中段代表續強 |
| 帶上影線的紅K | 上檔賣壓沉重；上影線越長賣壓越重 |
| 帶下影線的紅K | 支撐力道相對較強 |
| 上下影線約略等長的長紅K（迷線） | 多方略強格局 |
| 下影線明顯較長的紅K | 多方主導的趨強走勢 |
| 上影線明顯較長的紅K | 雖由多方主導，但要留意行情可能反轉 |

### 六種黑K基本型態（與紅K邏輯對稱互換多空）
長黑K（開=高、收=低）是最弱勢下跌格局；帶上影線的黑K代表買盤相對沉重；帶下影線的黑K代表雖跌但仍有支撐（空頭試圖反撲但力道不足）；上下影線等長的黑K（迷線）是空頭略強格局；下影線較長的黑K是多頭試圖反攻但功敗垂成的弱勢線；上影線較長的黑K代表空方力道仍強。

### 四種十字線型態
- **十字線**（開=收）：變盤意味濃厚，出現在波段高點→轉空訊號；出現在波段低點→轉多訊號。
- **倒T字線**（開=收=最低價）：又稱「避雷針」，賣方力量強過買方，出現在波段高檔要特別小心，可能反轉向下。
- **正T字線**（開=收=最高價）：偏多走勢，買方力量強過賣方，出現在波段低檔透露探底回升的訊號。
- **一字線**（開=收=高=低，即跳空漲/跌停鎖死）：代表盤勢躊躇或僵跌，需搭配成交量與委買委賣量判斷是否續漲/續跌。

### K線判讀的核心防騙原則（原書特別強調的風控觀念）
1. **K線可能被刻意作價**：有心人士或臨收盤前的突發消息，容易在最後一盤扭轉K線的「長相」，通常會在尾盤拉高或殺低，讓當日K線留下較長的上/下影線。
2. **長上影線的雙重解讀**：如果出現在「相對高檔區」（已上漲一段時間，例如近一週漲幅超過一成），代表主力已在大量出貨，應該看淡；但如果出現在「初步升段」（漲幅連3%都不到），反而可能是主力刻意拉尾盤嚇唬散戶洗盤，應該抱緊持股。
3. **長下影線的雙重解讀**：對稱地，出現在「相對低檔區」代表買氣轉強、止跌訊號；出現在「初步跌段」則可能是主力藉拉尾盤誘多、準備出貨，此時反而應儘早出脫。
4. **核心原則：不明確的訊號寧可觀望，不要冒險進出場**——這是貫穿全書、原書反覆強調的紀律要求。

## 二、複合式K線型態（兩根以上K線組合）

### 兩紅K組合（「日出/出頭」，多頭訊號，依強度細分）
1. **空頭反撲**：長紅後接長黑，黑K收盤價與紅K收盤價相近 → 多空不明，待下一根K線確認。
2. **空頭力道加強**：黑K收盤價侵入紅K實體一半以上 → 空頭力道轉強。
3. **空頭反撲力道最強（烏雲罩頂）**：黑K收盤價跌破紅K實體一半以下 → 多空易位機會大。

### 兩黑K組合（「日落/落尾」，空頭訊號，對稱細分）
① 多頭反攻（收盤價相近）；② 多頭力道加強（紅K收復黑K實體一半以上）；③ 多頭反撲力道最強／曙光乍現（紅K收復黑K實體一半以上更多）。

### 母子K線 / 子母K線
- **母子**（前長後短，前包後）：後線是黑K稱「陰母子」偏空解讀；後線是紅K稱「陽母子」偏多解讀。
- **子母**（前短後長，後包前）：後線收黑稱「陰子母」；收紅稱「陽子母」。若母線是長黑稱「長黑危樓」（強烈偏空表態）；母線是長紅稱「長紅玉柱」（強烈偏多表態）。
- **關鍵判讀規則**：這類型態出現在相對低檔位置且是「陽子母」，變盤轉強機率更高；出現在相對高檔位置且是「陰子母」，變盤轉弱機率更高。若不是出現在相對高低檔，只能視為「中繼」休息，需看後續K線是否出現明確突破再定奪。

### 雙K同頂 / 雙K同底
兩根K線最高價相等 → 該高點成為短線壓力（套牢區）；兩根K線最低價相等 → 該低點成為短線支撐（底部區）。

### 三根K線組合
- **紅三兵**（三根長紅）：後勢持續看漲，尤其出現在下降趨勢中的紅三兵是很強的反轉向上訊號，伴隨成交量放大更可信。
- **黑三兵**（三根長黑）：對稱地看跌，出現在上漲趨勢中是很強的反轉向下訊號。
- **兩紅夾一黑**：常被視為主力洗盤手法（「一日洗盤」），藉黑K讓散戶誤判出場，之後再拉紅K續攻。
- **晨星**（長黑＋極短實體/十字線＋長紅）：出現在下降趨勢末端，代表多頭短線勝出，行情可能反轉向上；第二根若是十字線則反轉機率更高。
- **夜星**（長紅＋極短實體/十字線＋長黑）：晨星的鏡像，出現在上漲趨勢末端，反轉向下訊號。
- **雙鴉躍空**（長紅後接跳空向下的兩根黑K）：出現在高檔盤整後，代表空方已戰勝多方，應先行避開。

## 三、技術指標

### 移動平均線（MA）
- 分類：MA5（週線）、MA10（雙週線）、MA20（月線）、MA60（季線）、MA240（年線）。
- **多頭排列**：短期均線 > 中期均線 > 長期均線（由上而下依序是MA5、MA20、MA60），股價趨勢看漲。
- **空頭排列**：短期均線 < 中期均線 < 長期均線，股價趨勢看跌。
- **黃金交叉**：短天期均線由下往上穿越長天期均線 → 短期進場訊號。
- **死亡交叉**：短天期均線由上往下跌破長天期均線 → 短期出場訊號。
- **均線糾結**：長短期均線小幅度交叉糾結、方向不明 → 代表盤整期，應保持觀望。
- **進出場訊號表**：收盤價同時大於MA5/MA20/MA60 → 進場訊號；同時小於 → 出場訊號。

### MACD（指數平滑異同移動平均線）
- 組成：DIF線（快線，短天期EMA差值）、MACD線（慢線）、DEF柱狀圖（DIF−MACD，也稱OSC）。
- DIF、MACD、DEF三者皆在零軸以上 → 典型多頭；三者皆在零軸以下 → 典型空頭。
- **黃金交叉**：DIF由下往上穿越MACD → 中長期漲勢確立，買進訊號。
- **死亡交叉**：DIF由上往下跌破MACD → 中長期跌勢確立，賣出訊號。
- **指標背離**（趨勢反轉信號）：
  - DEF在零軸以上但DIF/MACD在零軸以下 → 跌深反彈（空頭格局中的反彈，可搶反彈但要快進快出）。
  - DEF在零軸以下但DIF/MACD在零軸以上 → 漲多回檔（多頭格局中的回檔，可找機會放空但留意被軋空風險）。
  - 股價創新高但DEF未同步創新高 → 賣出訊號（背離）。
  - 股價創新低但DEF未同步創新低 → 買進訊號（正背離）。
- **重要限制**：MACD是「落後的確認指標」，不是領先的預測指標，個股已經走了一段之後才會反應，尤其在盤整時期使不上力，不建議單獨使用，應搭配其他指標。

### KD指標（隨機指標，參數通常設9,3,3）
- RSV = (今日收盤價 − 最近9日最低價) / (最近9日最高價 − 最近9日最低價) × 100
- 今日K值 = 前日K值×2/3 + 今日RSV×1/3；今日D值 = 前日D值×2/3 + 今日K值×1/3
- K值波動較D值大（快線vs慢線），K與D的交叉是較明確的買賣訊號。
- **買賣訊號門檻**：
  - K、D在80以上交叉 → 超買區，找賣點。
  - K、D在20以下交叉 → 超賣區，找買點。
  - K、D在50附近交叉且股價陷入盤整 → 訊號無效。
  - K>80且D>70 → 超買，找賣點；K<20且D<30 → 超賣，找買點。
  - D值>85 → 賣出訊號；D值<15 → 買進訊號。
- 現股當沖等短線操作可用5分K + KD指標作為觀盤重點：K值低檔買進、K值高檔賣出。

### RSI（相對強弱指標）
- 5日RSI = 100 × (1 − 1/(1 + 5日平均漲幅/5日平均跌幅))
- 數值介於0~100之間。
- **進出場門檻**：RSI<20且跌幅已深 → 逢低搶進；RSI>80且漲幅已大 → 準備出場；RSI介於20~80 → 一般交易、無明確訊號。
- 短天期RSI在長天期之上（如RSI5>RSI10>RSI20）→ 多頭行情，可找買點；反之為空頭行情。
- **反轉信號**：股價從超買區（80以上）快速掉落到30附近，或從超賣區（20以下）快速拉抬到70附近 → 強烈反轉信號。
- **背離**：股價創新高但RSI未同步創新高 → 漲勢後繼無力，找賣點；股價創新低但RSI未同步創新低 → 跌勢將盡，準備買進。
- **鈍化限制**：極端牛市/熊市中RSI會鈍化（貼在超買/超賣區不太變動），此時RSI幾乎派不上用場。

### BIAS乖離率
- 乖離率是以MA移動平均線為基準衍生出來的指標，用來看出目前股價偏離N日移動平均線（即市場平均成本）的「距離」，數值越大代表短線波動程度越大，越有可能出現獲利了結（股價下跌）或跌深反彈（股價上漲）。
- 乖離率 = (當天股價 − 最近N日股價平均數) / 最近N日股價平均數 × 100
- **正乖離／負乖離**：股價在平均成本線以上 → 正乖離；正乖離過高 → 容易引發獲利了結賣壓 → 漲多回檔。股價在平均成本線以下 → 負乖離；負乖離過高 → 容易引發搶反彈買盤 → 跌深反彈。
- **柱狀圖（乖離率差值）**：軟體圖表上乖離率除了顯示長天期、短天期兩條線之外，通常還會多畫一個柱狀圖，是用「短天期乖離率（如10日）」減去「長天期乖離率（如20日）」算出來的：短天期減長天期為正數 → 柱狀體顯示在水平線上方；為負數 → 柱狀體顯示在水平線下方。
- **買賣訊號門檻**：10日正乖離率≥5% → 短線超漲，賣出時機；10日負乖離率≥5% → 短線超跌，買進時機；20日正乖離率≥7.5% → 賣出時機；20日負乖離率≥7.5% → 買進時機。
- BIAS10與BIAS20曲線同時由上往下 → 空頭走勢；同時由下往上 → 多頭走勢。
- **失真限制**：乖離率在±15%以內才較具參考性，超過±15%容易指標鈍化；成交量過低（籌碼易被鎖定操弄）或受非經濟性因素（意外消息）干擾時也不適用。

### 多指標交叉驗證原則
原書反覆強調：任何單一技術指標都有盲點與可能被騙線的情況，**不應該只依賴單一指標**，應搭配K線、成交量、MA/MACD/KD/RSI等指標交叉驗證，才能提高準確度、降低被騙線或自己誤判的風險。

## 四、量價關係

### 量先價行的基本原則
- 成交量放大，行情容易上漲；成交量縮小，行情傾向下跌。
- 判斷「適宜成交量」的原則：①必須同時觀察價與量；②量能高低是相對數值（跟過去一段時期比），不是絕對數值；③成交量驟降是警訊。

### 量價背離的兩種訊號
1. **價跌量增**：
   - 出現在「末升段」（已經漲一大段、漲了一段時間）→ 主力/法人開始倒貨給散戶，是高檔出貨訊號，應該賣出。
   - 出現在「初升段或末跌段」（股價偏低）→ 部分主力低檔進貨，是底部買進訊號，可逢低承接。
2. **價漲量縮**：代表行情接近尾聲（追價的人變少），高檔區只剩少數人在玩，容易變成「抬轎」的犧牲者，此時不宜追高、也不是進場好時機。

### 量價同步訊號（趨勢確認/延續）
1. **價漲量增**：多頭訊號確立，通常出現在上漲初升段，少數在中升段；股價要續漲，成交量仍需持續增加。
2. **價跌量縮**：依所在階段解讀不同——初升段小跌是盤整（可續抱或逢低買）；初跌段是空頭訊號（應儘快出場）；末跌段代表空頭力竭（可注意買點）。

### 有量下跌 vs 無量下跌
- **無量下跌**：極度悲觀、沒人願意接手，容易跌停鎖死、持續破底。
- **有量下跌**：雖有人恐慌賣出，但也有人願意逢低承接，若股價已跌到接近底部區，可能是另一波反彈的開始。

## 五、宏觀經濟指標（可直接類比外匯基本面分析）

### 三大總經指標
1. **GDP成長率**：(本期GDP−前期GDP)/前期GDP×100。正數代表成長；已開發國家成長率通常<3%、開發中國家>5%；需連續觀察三四季，連續兩季負成長視為衰退。
2. **通貨膨脹率與失業率**：正常年頭兩者走向相反（經濟強→失業降、物價升；經濟弱→失業升、物價降）。兩者加總稱為「痛苦指數」。衡量通膨的三個指標：生產者物價指數(PPI，反映原物料)、消費者物價指數(CPI，反映消費端)、零售物價指數(RPI，反映零售端不含農產品)。
3. **利率政策傳導鏈**（直接對應外匯的利差交易邏輯）：通膨升溫 → 央行升息（緊縮）→ 該國利率高於他國 → 吸引外資流入 → 該國貨幣升值 → 升值過頭傷害出口 → 經濟轉弱 → 央行降息救市（貨幣寬鬆/財政擴張）→ 貨幣貶值救出口 → 循環反覆。這正是外匯市場「利差交易」與「央行政策分歧」邏輯的教科書版本。

### 景氣領先指標（預測未來）
由七項數據組成（外銷訂單動向指數、實質貨幣總計數M1B、股價指數、製造業景氣測驗點、實質半導體設備進口值、建築物開工樓地板面積、工業服務業受僱員工淨進入率），加權平均而成。
- **判斷規則**：指標>季均線 → 進場訊號（景氣轉好）；指標<季均線 → 出場訊號（景氣轉差）。

### 景氣對策信號（反映現況，屬落後指標，須逆勢操作）
由九項指標編製，以燈號表示：藍燈（景氣低迷）→買進訊號；黃紅燈/紅燈（景氣過熱）→賣出訊號。核心邏輯是「別人恐懼時貪婪、別人貪婪時恐懼」（逆勢操作），藍燈進場、黃紅燈以後出場。

### M1B / M2 貨幣總計數（資金動能，可類比外匯的央行資產負債表/貨幣供給對匯率的影響）
- M1B年增率上升 → 股市資金動能充沛，偏多；下降 → 資金動能萎縮，偏空。
- **黃金交叉**：M1B年增率曲線由下往上穿越M2年增率曲線 → 資金動能轉強，進場訊號。
- **死亡交叉**：M1B年增率曲線由上往下穿越M2年增率曲線 → 資金動能轉弱，出場訊號。

### 選股/選標的方法論
- **由上而下（TOP-DOWN）**：先看總體經濟大環境，再挑個股/標的（索羅斯派邏輯）。
- **由下而上（BOTTOM-UP）**：先看個體體質，再考慮大環境（巴菲特派邏輯）。
- 原書建議：淺碟型、易受外在因素影響的市場（原書指台股，可類比許多外匯商品同樣容易受美股/美元指數連動影響），較適合採「由上而下」方式。

## 六、短線交易的紀律原則（原書「現股當沖」章節中可轉用的部分）

以下規則抽掉台灣證交所特有的資格限制、手續費/證交稅細節（不適用外匯），只保留可轉用於任何短線交易的紀律原則：

1. **有賺就要跑**：不要預期買在最低賣在最高，停利點不要設太高、也不要太貪心；停利點可設在3%~5%左右的區間概念。
2. **避開低波動標的**：短線交易應選擇波動性較大、較活潑的標的，牛皮股（低波動防禦型）不適合短線操作。
3. **短週期K線+KD指標作為觀盤重點**：用5分鐘K線圖+KD指標作為短線觀盤重點——5分K轉強且KD值相對低檔時進場；股價連續突破盤中高點、且KD值相對高檔時出場。也可以在每個交易階段結束後，篩選短期均線（如5日線）翻揚、KD值在50以上的標的，作為下一階段可觀察的強勢名單。
4. **嚴守停損停利點**：短線交易紀律極重要，達到停利點要毫不貪心立即出場；方向看錯要壯士斷腕停損出場——短時間內想賺取利潤，必須「賺大賠小」，而不是靠高勝率。
5. **避免收盤前才進場**：越接近收盤賣壓通常越大，建議在開盤後前段時間就鎖定標的進場布局。
