# 河圖餅圖推演後天八卦

【澳門明星發展協會資情報｜資訊】今日（6月22日），澳門堪輿學家、易學家、河洛數學與幾何學研究專家、澳門明星發展協會-國際易學數理研究中心主席九玄風先生，發佈有關用「河圖」通過「圓周分割」，配合不同的二進制進位系統再結合代數運算，推演出「後天八卦」的方法。以下為九玄風所提供的具體方法：

## 一. 屬性定義

### (1) 乾坤六子卦父母區分

在八卦中，劃分為「乾坤六子卦」：

●全爻為陽或單一爻為陽之卦為父系卦(乾、坎、艮、震)

●全爻為陰或單一爻為陰之卦為母系卦(巽、離、坤、兑)

### (2) 四象與餘爻

在八卦中，四象和餘爻的看法按乾坤六子卦區分：

●父系卦(乾、坎、艮、震)：四象在下生，看下部(中、下爻)；餘爻浮在上，看上爻

●母系卦(巽、離、坤、兑)：四象在上生，看上部(上、中爻)；餘爻沉在下，看下爻

### (3) 四象中頂爻/底爻

八卦中四象的兩爻再分別按底、頂爻定義：

●父系卦(乾、坎、艮、震)：下部四象之下爻為底爻、下部四象之中爻為頂爻

●母系卦(巽、離、坤、兑)：上部四象之中爻為底爻、上部四象之上爻為頂爻

## 二. 八卦編碼

八卦的二進制編碼，分別按照頂爻、底爻、餘爻次序作二進制進位並轉換為十進制，父系卦分別對應中爻、下爻、上爻(「中下進法」)；母系卦分別對應上爻、中爻、下爻(「下進法」)，權重分別為1、2、4，當一個爻為陽，則獲得該爻相應權重之數；當一個爻為陰，則失去該爻相應權重之數，然後把該卦所得權重之數相加，則為該卦的十進制數。如父系艮☶卦，爻位由頂爻(中爻)、底爻(下爻)、餘爻(上爻)分別為陰(失1)、陰(失2)、陽(得4)，最終所得相加為4，即艮卦的十進制為4。再如母系巽☴卦，爻位由頂爻(上爻)、底爻(中爻)、餘爻(下爻)分別為陽(得1)、陽(得2)、陰(失4)，最終所得相加為3，即巽卦的十進制為3。

最後八個卦分別得出十進制0-7八數，需經過轉化匹配到河圖的1-4和6-9中(因河圖5、10為中樞而不配卦)，為先把0-7自然序數化，即全數加1成1-8；再把1-8中5或以上數作第二次加1，則得出最終映射數1-4和6-9。如父系艮卦為4，全數加1成5，但5≥5，所以需再加1而成6，即艮卦最終映射數為6。再如母系巽卦為3，全數加1成4，由於4≤5，所以保留原數4，即巽卦最終映射數為4。

最終得出映射數配卦為1坤、2坎、3震、4巽、6艮、7離、8兑、9乾。

## 三. 河圖四方數轉平分圓周兩層餅圖

河圖的四方數可分成內外兩層，把它轉化為「平分圓周兩層餅圖」，即由內至外，第一、二層分別按10(生數1+2+3+4)、30(成數6+7+8+9)份平分一個圓周，得出第一層(生數)每份所成的扇面佔整個圓的角度為36°；第二層(成數)每份所成的扇面佔整個圓的角度為12°。

## 四. 生成數組扇面所佔角度比值代換

把河圖四方數「平分圓周兩層餅圖」的各生成數組作扇面角度比值對比，並把河圖原數取代為角度比值，變為1→1、2→6、3→9、4→4、6→2、7→7、8→8、9→3，得出「河圖四方數平分圓兩層餅圖生成數組扇面角度比值圖」。計算方法為：

●1與6數組：1×360°/10=036°；6×360°/30=072°，036°：072° = 1：2

●2與7數組：2×360°/10=072°；7×360°/30=084°，072°：084° = 6：7

●3與8數組：3×360°/10=108°；8×360°/30=096°，108°：096° = 9：8

●4與9數組：4×360°/10=144°；9×360°/30=108°，144°：108° = 4：3

## 五. 內外層數順逆轉

### A法：外層數不動、內層數逆行

「河圖四方數平分圓兩層餅圖生成數組扇面角度比值圖」為內層1、4、6、9；外層2、3、7、8，正北1/2、正西3/4、正南6/7、正東8/9的「四方圖」，現轉為「外層數不動、內層數逆行圖」的「八方圖」，即外層數(2、3、7、8)居四正不動(正北2、正西3、正南7、正東8)；內層數(1、4、6、9)逆時針位移至相鄰四隅位(1正北→西北、4正西→西南、6正南→東南、9正東→東北)。

最終當按正南7作為錨點開始順時針方向觀察則得出閉環數列：

7正南 → 4西南 → 3正西 → 1西北 → 2正北 → 9東北 → 8正東 → 6東南 →

### B法：內層數不動、外層數順行

「河圖四方數平分圓兩層餅圖生成數組扇面角度比值圖」為內層1、4、6、9；外層2、3、7、8，正北1/2、正西3/4、正南6/7、正東8/9的「四方圖」，現轉為「內層數不動、外層數順行圖」的「八方圖」，即內層數(1、4、6、9)居四正不動(正北1、正西4、正南6、正東9)；外層數(2、3、7、8)順時針位移至相鄰四隅位(2正北→東北、3正西→西北、7正南→西南、8正東→東南)。

最終當按西南7作為錨點開始順時針方向觀察則得出閉環數列：

7西南 → 4正西 → 3西北 → 1正北 → 2東北 → 9正東 → 8東南 → 6正南 →

## 六. 三次方取個位數

### A：「外層數不動、內層數逆行圖」

「外層數不動、內層數逆行圖」原為以正南7作為錨點開始順時針方向得出閉環數列為：7正南 → 4西南 → 3正西 → 1西北 → 2正北 → 9東北 → 8正東 → 6東南 →。

當各數自乘3次，並取個位數後，如原數7，7³=343，個位為3，即7轉為3。數列變為：3正南 → 4西南 → 7正西 → 1西北 → 8正北 → 9東北 → 2正東 → 6東南 →。形成「外層數不動、內層數逆行3次方取個位數圖」。

### B：「內層數不動、外層數順行圖」

「內層數不動、外層數逆行圖」原為以西南7作為錨點開始順時針方向得出閉環數列為：7西南 → 4正西 → 3西北 → 1正北 → 2東北 → 9正東 → 8東南 → 6正南 →。

當各數自乘3次，並取個位數後，如原數7，7³=343，個位為3，即7轉為3。數列變為：3西南 → 4正西 → 7西北 → 1正北 → 8東北 → 9正東 → 2東南 → 6正南 →。形成「內層數不動、外層數順行3次方取個位數圖」。

## 七. 旋轉

### A：「外層數不動、內層數逆行3次方取個位數圖」逆時針旋轉90°

「外層數不動、內層數逆行3次方取個位數圖」原為以正南3作為錨點開始順時針方向得出閉環數列為： 3正南 → 4西南 → 7正西 → 1西北 → 8正北 → 9東北 → 2正東 → 6東南 →。

現把圖逆時針旋轉90°。數列排佈變為：3正東 → 4東南 → 7正南 → 1西南 → 8正西 → 9西北 → 2正北 → 6東北 →。形成「外層數不動、內層數逆行3次方取個位數逆時針旋轉90°圖」。

### B：「內層數不動、外層數順行3次方取個位數圖」逆時針旋轉135°

「內層數不動、外層數順行3次方取個位數圖」原為以西南3作為錨點開始順時針方向得出閉環數列為： 3西南 → 4正西 → 7西北 → 1正北 → 8東北 → 9正東 → 2東南 → 6正南 → 。

現把圖逆時針旋轉135°。數列排佈變為：3正東 → 4東南 → 7正南 → 1西南 → 8正西 → 9西北 → 2正北 → 6東北 →。形成「內層數不動、外層數順行3次方取個位數逆時針旋轉135°圖」。

### 小結

最後無論是「外層數不動、內層數逆行3次方取個位數逆時針旋轉90°圖」還是「內層數不動、外層數順行3次方取個位數逆時針旋轉135°圖」，皆以正東3作為錨點開始順時針方向得出閉環數列為：3正東 → 4東南 → 7正南 → 1西南 → 8正西 → 9西北 → 2正北 → 6東北 →。

## 八. 配映射卦

最終把映射卦1坤、2坎、3震、4巽、6艮、7離、8兑、9乾，配對到「外層數不動、內層數逆行3次方取個位數逆時針旋轉90°圖」/「內層數不動、外層數順行3次方取個位數逆時針旋轉135°圖」，得出以正東3震作為錨點開始順時針方向排出後天八卦序列循環：3震正東 → 4巽東南 → 7離正南 → 1坤西南 → 8兑正西 → 9乾西北 → 2坎正北 → 6艮東北 →。
